# 三类文案规格（口播 / 长文 / 短文）

改写或分发前，读目标类型对应一节。

## 口播（视频文案）

**规格**：1-3 分钟，字数 ≈ 时长(分钟) × 260。短句为主，避免书面语和长从句，每句适合口读。

**标准结构**：

```text
钩子（0-5s）    一句话让目标用户停下，无自我介绍开场
铺垫（5-15s）   点痛点/立冲突，说明"为什么该听我讲"
主体（15s-2min）2-3个信息点，每点=观点+实操演示/例子
金句收尾        一句可被截图转发的总结（同时是封面/标题候选）
CTA             引导关注/评论/公众号，每条视频只放一个动作
```

**钩子库**：

| 类型 | 模板 | 适用 |
|---|---|---|
| 反常识 | "你以为xxx，其实xxx" | 认知类选题 |
| 结果前置 | "我用AI把xx时间从3小时压到10分钟" | 工作流实战 |
| 痛点直击 | "还在手动xxx的人，这条视频能救你" | 效率工具 |
| 热点借力 | "xx刚发布，我第一时间试了，说三个真话" | 热点选题 |
| 身份筛选 | "做自媒体的注意，这个功能别错过" | 垂类人群 |

**检查清单**：

- [ ] 钩子前 5 秒有停留理由
- [ ] 每个信息点有具体案例/数字，无空泛建议
- [ ] 口读一遍顺口，无绕口长句
- [ ] 金句可独立截图
- [ ] 只有一个 CTA
- [ ] 字数符合目标时长

## 长文（公众号 / 知乎 / 推特长文）

**规格**：1500-3000 字。口语化风格，别写成官方教程腔。没有可扩写的细节就写短一点，不注水。

**结构**：开头钩子（可复用/改写口播钩子）→ 小标题分节 → 结尾引导关注 + 预告下期。

**要求**：

1. 点到为止的操作步骤扩成可跟做的完整教程，标注 `[截图位]` 让用户补图。
2. 标题给 5 个备选：2 个数字型、2 个痛点型、1 个热点型。
3. 平台微调：知乎开头先回应问题本身、可更论证化；推特长文压到 2000 字内、段落更碎、少用小标题。

**检查清单**：

- [ ] 每节小标题下有干货，无凑字段落
- [ ] 步骤可跟做，截图位已标
- [ ] 结尾有下期预告或引导动作
- [ ] 读起来仍是作者的口吻

## 短文（推特）

**规格**：两组产出——

1. **一条 thread（3-8 条推文）**：首推 = 钩子 + 结论前置，可独立成立（不依赖后文）；中间每推一个信息点；末推 CTA。每条 ≤280 字符。
2. **两条独立金句帖**：最有转发价值的观点，一句话 + 一行展开。

**语言**：直接、具体、有数字。hashtag 最多 1-2 个，不堆砌。

**检查清单**：

- [ ] 首推单独读也成立
- [ ] 每条 ≤280 字符
- [ ] 金句帖不解释背景也能看懂
- [ ] 无 hashtag 堆砌
